# PCB · Noisy Cricket Mk II Rev A

[Project overview](../../README.md) · [Simulations](../simulations/README.md) · [CAD](../cad/README.md)

This directory contains the ordered [Noisy Cricket Mk II Rev A](Noisy_Cricket_MkII/README.md) board design. It combines the amplifier circuit, front controls, and terminals for off-board connections on a two-layer PCB.

Open [Noisy_Cricket_MkII.kicad_pro](Noisy_Cricket_MkII/Noisy_Cricket_MkII.kicad_pro) in KiCad 9 or a compatible newer version. Keep the local `Cricket.pretty` footprint library and `fp-lib-table` with the project.

The [board guide](Noisy_Cricket_MkII/README.md) describes the circuit, parts, manufacturing files, and checks. A [PDF schematic](Noisy_Cricket_MkII/Schematic.pdf) is available for reading without KiCad. The saved check reports do not replace testing the assembled board.
